# 🌸 Period Tracker
 
Application desktop de suivi du cycle menstruel développée en Python.
 
## ✨ Fonctionnalités prévues
 
### Version 1
- Ajout de périodes
- Historique des cycles
- Calcul du cycle moyen
- Prédiction des prochaines règles
 
### Version 2
- Suivi de l'humeur
- Suivi de la fatigue
- Suivi des douleurs
- Notes personnelles
 
### Version 3
- Statistiques avancées
- Graphiques
- Export des données
- Analyse des cycles
 
## 🛠️ Technologies
 
- Python 3
- CustomTkinter
- SQLite
- Matplotlib

## 🚀 Installation

Créer un environnement virtuel :

`python3 -m venv venv
    source venv/bin/activate`

Installer les dépendances :

`pip install -r requirements.txt`


Lancer l'application :

`python main.py`
